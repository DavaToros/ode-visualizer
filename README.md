# 🌊 ODE Direction Field & Trajectory Visualizer

Интерактивный веб-симулятор и визуализатор обыкновенных дифференциальных уравнений (ОДУ) первого порядка в реальном времени.

Позволяет исследовать поведение решений ДУ через векторные поля направлений и численно строить интегральные кривые (задачу Коши) в один клик или касание.

## ✨ Возможности

- **Универсальный парсер ввода:** 
  - Поддержка явного вида через производную: `y' = f(x, y)`, `dy/dx = f(x, y)`.
  - Поддержка симметричной формы через дифференциалы: `P(x, y)dx + Q(x, y)dy = 0`.
  - Автоматическая нормализация выражений: понимает неявное умножение (`2x`, `xy`, `2sin(x)`), скобки и естественную математическую запись.
- **Векторное поле (карта течений):**
  - Расчет изоклин и отрисовка нормализованных касательных векторов на холсте HTML5 Canvas.
  - Устойчивость к вертикальным касательным (отсутствие сингулярности при делении на ноль).
- **Численное решение задачи Коши:**
  - Трассировка интегральных кривых методом **Рунге-Кутты 4-го порядка (RK4)**.
  - Двустороннее интегрирование (вперед и назад во времени/параметру от точки старта).
- **Экранная клавиатура:**
  - Быстрый ввод спецсимволов и функций (`sin`, `cos`, `exp`, `ln`, `sqrt`, `^`, дифференциалы).
- **Полная адаптивность (Mobile Ready):**
  - Поддержка мыши и сенсорного ввода (`Pointer Events API`).
  - Адаптивная верстка под смартфоны и планшеты.
  - Защита от случайного скролла при интерактивном рисовании.

## 🧮 Примеры уравнений для теста

| Тип уравнения | Пример записи | Что визуализирует |
| :--- | :--- | :--- |
| **Окружности / Центр** | `x*dx + y*dy = 0` | Замкнутые концентрические орбиты вокруг $(0, 0)$ |
| **Экспоненциальный рост** | `y' = y` | Семейство экспонент $y = C e^x$ |
| **Параллельные прямые** | `(2x + y + 1)dx - (4x + 2y - 3)dy = 0` | Поле с асимптотой $2x + y - 1 = 0$ |
| **Логистический рост** | `y' = y*(1 - y)` | Модель насыщения популяции (устойчивое состояние $y=1$) |
| **Тригонометрическое поле** | `y' = sin(x) * cos(y)` | Сетка седловых точек и узлов |

## 🛠 Математический стек под капотом

1. **Параметризация:**  
   Уравнение $P(x, y)\,\mathrm{d}x + Q(x, y)\,\mathrm{d}y = 0$ преобразуется в динамическую систему:
   $$\frac{\mathrm{d}x}{\mathrm{d}t} = Q(x, y), \quad \frac{\mathrm{d}y}{\mathrm{d}t} = -P(x, y)$$
   Это снимает ограничение классического вида $y' = f(x, y)$, где невозможно преодолеть бесконечный наклон.

2. **Численный интегратор:**  
   Реализован классический алгоритм **Рунге-Кутты 4-го порядка (RK4)** с фиксированным шагом $h = 0.05$:
   $$k_1 = f(t_n, y_n)$$
   $$k_2 = f\left(t_n + \frac{h}{2}, y_n + h\frac{k_1}{2}\right)$$
   $$k_3 = f\left(t_n + \frac{h}{2}, y_n + h\frac{k_2}{2}\right)$$
   $$k_4 = f(t_n + h, y_n + h k_3)$$
   $$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

3. **Синтаксический анализ:**  
   Математические выражения компилируются на лету в абстрактное синтаксическое дерево (AST) с помощью [math.js](https://mathjs.org/).
